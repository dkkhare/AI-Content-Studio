# AI Content Studio

Create professional AI videos from books, PDFs, articles, poetry, and scripts.

## Features

- OCR PDF
- Voice Cloning
- Talking Avatar
- Subtitle Generation
- Video Composer
- Batch Rendering
- Safe application updates
- Redacted local support diagnostics

## Platform

- Windows 11
- Python 3.11
- PySide6
