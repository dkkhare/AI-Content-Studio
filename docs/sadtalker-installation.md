# SadTalker requirements and installation

AI Content Studio uses SadTalker as an external, optional runtime for the
**Talking Head Series** feature. SadTalker animates a portrait from each F5-TTS
narration segment; FFmpeg then assembles the segments into ordered episode MP4s.

Use only a portrait and voice for which you have authorization. AI Content
Studio requires rights confirmation before generation.

## What is and is not installed automatically

AI Content Studio does not bundle SadTalker, its checkpoints, FFmpeg, CUDA,
PyTorch, or GPU drivers. Install SadTalker in its own Python environment. Do not
install its pinned dependencies into AI Content Studio's Python 3.11
environment.

The upstream SadTalker instructions use Python 3.8. In AI Content Studio, select:

- **SadTalker folder**: the folder containing `inference.py`
- **SadTalker Python**: the full path to the Python executable in the dedicated
  SadTalker environment

Then click **Check Setup** before previewing or generating a series.

## Hardware requirements

These are practical planning guidelines; actual memory and time depend on image
size, enhancement, episode duration, driver, and PyTorch build.

| Component | Minimum test setup | Recommended for long series |
| --- | --- | --- |
| OS | 64-bit Windows 10/11, Ubuntu 22.04+, or supported macOS | Current patched OS |
| CPU | 4 modern cores | 6–8 cores or more |
| System RAM | 8 GB | 16 GB; 32 GB for concurrent/local AI work |
| GPU | CPU mode or compatible accelerator | NVIDIA CUDA GPU with 6–8 GB+ VRAM |
| 4 GB NVIDIA GPU | Use 256px, crop mode, no enhancer, one job at a time | Expect slower work and possible fallback |
| Apple Silicon | CPU/MPS compatibility varies by dependency | 16 GB unified memory or more |
| Disk for SadTalker | About 5 GB free | 10 GB free for environment/models |
| Working disk | At least 20 GB free | SSD with 50 GB+ free for a book series |

CPU-only rendering is possible on some configurations but can be extremely
slow. The application's default 256px setting is intended to reduce memory use.
The optional GFPGAN enhancer and 512px rendering need more memory and time.

For a 15-minute episode series, storage consumption can be much larger than the
final MP4 because narration WAVs, segment MP4s, manifests, and partial outputs
are retained for safe resume. Keep projects on an SSD and do not let the system
sleep during generation.

## Common software requirements

- Git
- Git LFS is not normally required for the standard checkpoint download
- Python 3.8 environment dedicated to SadTalker
- FFmpeg available on `PATH`
- SadTalker repository and checkpoints
- F5-TTS configured separately for sampled-voice narration
- current GPU driver; compatible CUDA/PyTorch build for NVIDIA acceleration
- internet access for initial source, package, and model downloads
- no SadTalker API key is required

Official resources:

- [SadTalker repository](https://github.com/OpenTalker/SadTalker)
- [SadTalker releases and checkpoint packages](https://github.com/OpenTalker/SadTalker/releases)
- [Upstream installation notes](https://github.com/OpenTalker/SadTalker/blob/main/docs/install.md)

## Windows installation

The following PowerShell procedure uses Miniconda/Anaconda because SadTalker's
upstream dependency set targets Python 3.8. Run commands as a normal user.

### 1. Install prerequisites

Install:

1. [Git for Windows](https://git-scm.com/download/win)
2. [Miniconda](https://docs.conda.io/projects/miniconda/en/latest/)
3. FFmpeg from the [official FFmpeg download page](https://ffmpeg.org/download.html)
4. The current NVIDIA driver if using a supported NVIDIA GPU

Add FFmpeg's `bin` folder to `PATH`, restart PowerShell, and verify:

```powershell
git --version
conda --version
ffmpeg -version
```

If `conda` is unavailable in ordinary PowerShell, use **Anaconda Prompt** or
initialize PowerShell once with `conda init powershell`, then open a new shell.

### 2. Clone SadTalker

```powershell
cd C:\AI-Tools
git clone https://github.com/OpenTalker/SadTalker.git
cd SadTalker
```

Avoid moving this folder after configuring AI Content Studio.

### 3. Create the isolated environment

```powershell
conda create -n sadtalker python=3.8 -y
conda activate sadtalker
python -m pip install --upgrade pip setuptools wheel
python -m pip install -r requirements.txt
```

PyTorch/CUDA compatibility changes over time. If the requirements install does
not provide a build suitable for your GPU, use the command generated by the
[official PyTorch installer](https://pytorch.org/get-started/locally/) for your
driver and CUDA choice, then reinstall SadTalker's remaining requirements.

Verify:

```powershell
python -c "import torch; print(torch.__version__); print('CUDA:', torch.cuda.is_available())"
python -c "import cv2, numpy; print('dependencies OK')"
```

### 4. Download checkpoints

Download the current checkpoint package from
[SadTalker Releases](https://github.com/OpenTalker/SadTalker/releases). Extract
it so the repository contains at least:

```text
C:\AI-Tools\SadTalker\
├── inference.py
├── checkpoints\
│   ├── SadTalker_V0.0.2_256.safetensors
│   ├── SadTalker_V0.0.2_512.safetensors
│   ├── mapping_00109-model.pth.tar
│   └── mapping_00229-model.pth.tar
└── gfpgan\
    └── weights\
```

Package contents can change upstream. Preserve the package's directory
structure rather than copying all files into one folder.

### 5. Run a direct smoke test

Prepare a front-facing portrait and a short WAV file:

```powershell
python inference.py --driven_audio "C:\Samples\voice.wav" --source_image "C:\Samples\portrait.png" --result_dir "C:\Samples\sadtalker-result" --size 256 --preprocess crop
```

Confirm that an MP4 appears below the result folder. For a 4 GB GPU, start with
`--size 256 --preprocess crop` and do not add GFPGAN.

Find the Python path AI Content Studio must use:

```powershell
python -c "import sys; print(sys.executable)"
```

It will resemble
`C:\Users\NAME\miniconda3\envs\sadtalker\python.exe`.

## Ubuntu installation

These instructions target Ubuntu 22.04 or newer. Use a normal user, not
`sudo pip`.

### 1. Install system packages and Miniconda

```bash
sudo apt update
sudo apt install -y git ffmpeg wget build-essential
git --version
ffmpeg -version
```

Install Miniconda from its official Linux installer, reopen the shell, and
verify `conda --version`.

For NVIDIA acceleration, install a suitable current driver using Ubuntu's
supported driver mechanism. Confirm `nvidia-smi` works before selecting a
CUDA-enabled PyTorch build.

### 2. Clone and create the environment

```bash
mkdir -p "$HOME/AI-Tools"
cd "$HOME/AI-Tools"
git clone https://github.com/OpenTalker/SadTalker.git
cd SadTalker
conda create -n sadtalker python=3.8 -y
conda activate sadtalker
python -m pip install --upgrade pip setuptools wheel
python -m pip install -r requirements.txt
```

If needed, install the matching PyTorch build using the command from the
official PyTorch selector.

### 3. Download models and verify

The upstream repository provides a download script for Linux/macOS:

```bash
bash scripts/download_models.sh
test -f inference.py
find checkpoints -maxdepth 1 -type f
python -c "import torch; print(torch.__version__); print('CUDA:', torch.cuda.is_available())"
```

If the script fails or upstream URLs change, download the checkpoint archive
from the official SadTalker Releases page and extract it without changing its
folder layout.

### 4. Smoke test

```bash
python inference.py \
  --driven_audio "$HOME/Samples/voice.wav" \
  --source_image "$HOME/Samples/portrait.png" \
  --result_dir "$HOME/Samples/sadtalker-result" \
  --size 256 \
  --preprocess crop
python -c "import sys; print(sys.executable)"
```

## macOS installation (experimental)

SadTalker upstream documents a method tested on an M1 Mac, but AI Content
Studio does not currently have a macOS SadTalker CI gate. PyTorch, torchvision,
dlib, face-alignment, and MPS compatibility can vary by macOS and chip. Treat
this as experimental and perform a short direct smoke test first.

Use a native terminal architecture. On Apple Silicon, `uname -m` should report
`arm64`; avoid mixing Rosetta and arm64 packages.

### 1. Install prerequisites

Install Apple Command Line Tools, Homebrew, and Miniconda/Miniforge:

```bash
xcode-select --install
brew install git ffmpeg cmake
git --version
ffmpeg -version
uname -m
```

Miniforge is often convenient on Apple Silicon, but use one Conda distribution
consistently.

### 2. Clone and install

```bash
mkdir -p "$HOME/AI-Tools"
cd "$HOME/AI-Tools"
git clone https://github.com/OpenTalker/SadTalker.git
cd SadTalker
conda create -n sadtalker python=3.8 -y
conda activate sadtalker
python -m pip install --upgrade pip setuptools wheel
python -m pip install torch torchvision torchaudio
python -m pip install -r requirements.txt
python -m pip install dlib
bash scripts/download_models.sh
```

If `dlib` fails, confirm Command Line Tools and CMake are installed. Do not
silently mix x86_64 and arm64 wheels. Intel Macs use CPU rendering and may be
very slow.

### 3. Verify and smoke test

```bash
python -c "import platform, torch; print(platform.machine()); print(torch.__version__); print('MPS:', hasattr(torch.backends, 'mps') and torch.backends.mps.is_available())"
python inference.py \
  --driven_audio "$HOME/Samples/voice.wav" \
  --source_image "$HOME/Samples/portrait.png" \
  --result_dir "$HOME/Samples/sadtalker-result" \
  --size 256 \
  --preprocess crop
python -c "import sys; print(sys.executable)"
```

A reported MPS device does not guarantee every SadTalker operation will execute
on Metal. If an MPS-specific operation fails, try CPU execution or use a
supported NVIDIA/Linux/Windows workstation.

## Configure AI Content Studio

1. Run AI Content Studio from the current `main` source checkout.
2. Create or open a project.
3. Open **Talking Head Series**.
4. Select the complete book, writer portrait, authorized voice sample, and the
   exact transcript of that voice sample.
5. Set **SadTalker folder** to the cloned repository folder containing
   `inference.py`.
6. Set **SadTalker Python** to the executable printed by
   `python -c "import sys; print(sys.executable)"` inside the SadTalker
   environment.
7. Keep **Size** at 256 and use crop preprocessing for the first test.
8. Confirm the rights checkbox.
9. Click **Check Setup**. Resolve every required failure.
10. Preview the episode plan, then generate/resume the series.

The default series outputs are stored inside the project output area and include
numbered episode MP4s, narration/segment working files, a series manifest,
checksums, and an M3U playlist.

## Troubleshooting

| Problem | Checks |
| --- | --- |
| `inference.py` not found | Select the SadTalker repository root, not `checkpoints` or `src` |
| Checkpoints missing | Re-extract the official model package and preserve its directories |
| FFmpeg missing | Run `ffmpeg -version` in a newly opened terminal and restart the app |
| Wrong Python | Use the exact executable printed from the activated `sadtalker` environment |
| `ModuleNotFoundError` | Activate the SadTalker environment and reinstall `requirements.txt` there |
| CUDA unavailable | Check `nvidia-smi`, driver, PyTorch build, and `torch.cuda.is_available()` |
| CUDA out of memory | Use 256px/crop, disable enhancer, close GPU apps, and generate one job at a time |
| NumPy/torchvision/scipy conflict | Recreate the isolated environment; do not upgrade packages indiscriminately |
| macOS architecture error | Ensure shell, Conda, Python, and wheels all use the same architecture |
| No MP4 produced | Run the direct smoke command and inspect its terminal error before using the app |
| Long job interrupted | Reopen the same project and use Generate/Resume; do not delete checkpoint files |
| Poor lip sync | Use clean narration audio, a clear front-facing portrait, and avoid occluded mouths |

When reporting a failure, include OS, CPU, RAM, GPU/VRAM, driver, Python path,
PyTorch version, CUDA/MPS availability, exact command, and the final error
lines. Remove personal paths and do not upload private book, portrait, voice,
API keys, or uninspected support bundles.
